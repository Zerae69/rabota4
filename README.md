Трекер прочитанных книг

Назначение приложения:
Это консольное приложение на Python для учета прочитанных книг.
Позволяет добавлять книги, просматривать список, считать статистику и удалять записи.

Как запустить?
Ввести: python main.py

Пример работы
1. Добавить книгу
2. Показать все книги
3. Средняя оценка
4. Статистика по авторам
5. Удалить книгу
6. Выход
